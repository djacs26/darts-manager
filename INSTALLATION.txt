MISE A JOUR DARTS MANAGER 4.4.1
1. Décompresser ce ZIP.
2. Dans GitHub, ouvrir le dépôt djacs26/darts-manager puis Add file > Upload files.
3. Envoyer les 8 fichiers de ce dossier à la racine du dépôt (pas le dossier parent).
4. Vérifier que index.html, sw.js, manifest.webmanifest et les icônes sont à la racine.
5. Cliquer Commit changes.
6. Attendre la publication GitHub Pages, puis ouvrir https://djacs26.github.io/darts-manager/?v=441
7. Sur Android, fermer l'ancienne application installée, ouvrir le lien dans Chrome et actualiser.
IMPORTANT : exporter les données depuis l'onglet Statistiques avant la mise à jour. Les données locales ne sont pas synchronisées entre appareils.
