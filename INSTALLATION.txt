MISE A JOUR DARTS MANAGER 4.0.1
1. Décompresser l'archive sur le téléphone.
2. Dans GitHub, ouvrir le dépôt darts-manager puis Add file > Upload files.
3. Envoyer les 8 fichiers contenus dans ce dossier directement à la racine du dépôt (pas le ZIP, pas un sous-dossier).
4. Valider avec Commit changes sur la branche main.
5. Attendre le déploiement GitHub Pages, puis ouvrir https://djacs26.github.io/darts-manager/ et actualiser.
6. Si l'ancienne version reste affichée, fermer complètement le navigateur puis rouvrir le site. Le cache applicatif est renouvelé en version 4.

IMPORTANT : les profils et statistiques sont enregistrés sur l'appareil. Exporter une sauvegarde avant toute suppression des données du navigateur.
