MISE A JOUR DARTS MANAGER 4.2.0
1. Décompresser cette archive.
2. Envoyer les 8 fichiers directement à la racine du dépôt GitHub (pas le ZIP et pas un sous-dossier).
3. Valider le commit sur la branche main.
4. Ouvrir https://djacs26.github.io/darts-manager/ dans Chrome et actualiser.
5. Si l'ancienne version reste affichée, fermer l'onglet, rouvrir le site et actualiser une nouvelle fois.
Les données locales restent dans le navigateur, mais il est recommandé d'exporter une sauvegarde avant la mise à jour.
